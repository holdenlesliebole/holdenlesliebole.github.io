Browser CFD — a validated lattice-Boltzmann artifact

A self-contained 2D lattice-Boltzmann (D2Q9 BGK) flow solver running live in the browser — plain JavaScript, no build step, no dependencies. The point isn't the animation. Every case ships next to a validation panel and an explicit statement of what the model can and cannot claim. Four canonical flows, each checked against an exact solution or a canonical correlation in a reproducible Node harness.
A validation harness that only shows you the numbers that pass is not validation. Knowing exactly what a model can and cannot claim is what separates an engineering tool from a demo.
Method. D2Q9 BGK lattice-Boltzmann — a mesoscopic (lattice-kinetic) scheme, not a direct Navier–Stokes discretization; the macroscopic limit recovers weakly-compressible NS. Streaming is the time integration (explicit, 2nd-order). One geometry-agnostic engine (lbm.js, ~430 lines); geometry is per-node flags.  Validation. Each case has a Node harness asserting agreement with its reference; the cylinder additionally carries a decomposed error budget (blockage vs resolution convergence studies).  2D & laminar by design — turbulence is out of envelope (the 3D energy cascade needs vortex stretching, which vanishes in 2D).  Source & harnesses: ~/Documents/CFD/browser_lbm/.
